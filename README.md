
# AI-Based Network Traffic Anomaly Detection

## Overview
This project uses Machine Learning to identify unusual
patterns in network traffic using the Isolation Forest
algorithm.

## Objectives
- Analyse network traffic patterns.
- Identify abnormal network behaviour.
- Classify traffic as normal or anomalous.
- Visualise network traffic statistics.
- Generate downloadable analysis reports.

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Machine Learning Algorithm
Isolation Forest is used for unsupervised anomaly detection.

## Features
- Synthetic network traffic generation.
- Configurable anomaly detection.
- Interactive visualisation dashboard.
- Traffic filtering.
- CSV report download.

## Installation

Clone the repository:

    git clone https://github.com/kuldeepsulaniya98-hash/AI-Network-Anomaly-Detection.git

Install dependencies:

    pip install -r requirements.txt

Run the application:

    streamlit run app.py

## Disclaimer
This is an educational demonstration using synthetic
network traffic data. It is not a production-grade
intrusion detection system.
